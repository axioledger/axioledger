Onboarding & Authentication
W1–W2 · 22 screens
Design principle: First-impression trust. Mỗi màn hình Onboarding phải truyền tải sự an toàn và tốc độ — zero cognitive load, max 1 action per screen.

Logo center, skeleton shimmer 1.2s, version string muted bottom
Critical path
Force Update
Full-screen blocker, CTA "Cập nhật ngay", non-dismissible bottom sheet
Edge case
System Maintenance
Illustration + ETA countdown timer + "Nhận thông báo khi xong"
Edge case
Onboarding 1–3
Swipeable slides, progress dots, "Bỏ qua" top-right, last slide CTA primary
New
Dynamic Onboarding

Terms Modal
Bottom sheet, scrollable WebView, sticky "Đồng ý" disabled until scroll end
Compliance
Welcome / Select Mode
2 large tap targets: Đăng nhập / Đăng ký. Social login options below divider
Critical path
Phone / Email Input
Country code picker (+84 default), inline format validation, keyboard "Next"

OTP Input
6-cell auto-advance, SMS autofill, 60s countdown Resend, "Gọi điện" fallback

Shake + red flash on mismatch, max 3 attempts before reset flow

8
System States & Edge Cases
W10 · 11 screens
Design principle: Empty states phải có illustration + call-to-action rõ ràng, không bao giờ hiện màn hình trắng. Error messages phải plain language, không dùng error code raw.
No Internet
Offline illustration, toast banner, cache data vẫn visible muted, retry button
Edge case
Server Error (500)
Fun illustration, "Chúng tôi đang sửa", incident ID nhỏ, retry + status page link
Edge case
Session Expired
Auto-logout modal after 5 min idle, "Đăng nhập lại" button, state preserved
Edge case
Empty Transaction
Illustration "Chưa có giao dịch nào", CTA "Thực hiện giao dịch đầu tiên"
Edge case
Empty Portfolio
Illustration, "Mua Crypto đầu tiên" CTA, market trending bar below
Edge case
Empty Cards
Card outline dashed, "Phát hành thẻ đầu tiên" primary CTA
Edge case
Jailbreak Warning
Full-screen blocker, không dismissible, contact support link only
Critical path
Account Blocked
Reason summary, unblock guide steps, escalation CS button
Edge case
Screenshot Blocked
UITextField.isSecureTextEntry + custom black overlay khi screenshot detected
